# 迁移到线上 API：节点耗时与国内平台价格（10-04 调研）

作者 10-04 问：现在哪个节点最慢？想迁到线上 API，国内各家多少钱、一小时大概花多少。
节点耗时的实测在 `../实测-M2.md`「各节点耗时」，这里只引结论；价格是 10-04 查的北京地域后付费刊例价，不含活动折扣。
标 ★ 的又对过官方页或搜索摘要，其余是子代理从官方页读的（火山的文档页要 JS 渲染，子代理经它的文档接口读了 09-29 版的官方 PDF）。

> 10-04 后续：翻译已换成 deepseek-flash（整场对话做上下文、走缓存），实测见 `../实测-M2.md`「翻译接入 DeepSeek」：
> 每句约 1 秒，缓存命中约 98.7%，头一小时约 0.5–1 元（高峰）。

## 结论先说

- **最慢的不是模型**：从开口到配音就绪中位 17.4 秒、p95 27–30 秒（D=30），里面 40% 是 YouTube 到货（5 秒一片 + 经代理抖动），
  25% 是等人说完，这两块换 API 帮不上。
- 自己的节点里最慢的是**断句 + 识别**（均值 3.5 秒、p95 约 8.5 秒），真算只占约 1 秒，其余是每 2 秒一轮的轮询、1 秒尾保护、等句末标点。
  换**流式识别 API**（服务端 VAD 出句尾）预计能压到 1–2 秒，一小时约 1 元，是最值得先换的一块（压缩幅度待实测）。
- 配音 1.1 秒/句、翻译 0.4 秒/句，换 API 不会更快（还要加网络往返），换的好处是**腾出显存**（翻译 4.9G + 配音 6.1G），
  翻译还可能**换到更大的模型**。
- **一小时多少钱**（按密集讲话的一小时算，见下面「用量口径」）：
  | 方案 | 组成 | ¥/小时 |
  | --- | --- | --- |
  | 只换识别 + 翻译，配音留本机 | 豆包流式识别 2.0 + qwen-flash（或 qwen-mt-plus / DeepSeek） | **约 1.1–1.5** |
  | 全换，最省 | 豆包流式识别 2.0 + qwen-flash + cosyvoice-v3.5-flash（复刻免费） | **约 3.2** |
  | 全换，质量优先（不按音色收费的） | 豆包流式识别 2.0 + qwen-mt-plus / DeepSeek + cosyvoice-v3.5-plus | **约 5.4** |
  | 端到端同传（阿里） | qwen3.8 / 3.5-livetranslate-flash-realtime，自带说话人分离和实时复刻 | **约 8–9** |
  | 端到端同传（火山） | 豆包同声传译 2.0（Seed LiveInterpret 2.0） | **约 24–25** |
- **按音色收费的复刻别用**：新闻台一小时分出 27–46 个说话人（声纹门槛 0.45 宁拆不合），MiniMax 9.9 元/个就是约 270–460 元/小时，
  火山声音复刻后付费 138 元/个要几千元/小时。只有阿里 CosyVoice（创建免费，账号上限 1000 个）、qwen3-tts-vc（0.01 元/个）、
  硅基流动（每次请求带参考音，不收复刻费）这几家能跟上「一场几十个人」的用法。
- 建议顺序：先换识别（便宜、能压延迟），再换翻译（便宜、可能更准），配音最后、先小样对比，因为 API 版会丢掉现在的两样东西：
  **每句拿这句原声当情绪参考**、**按目标时长合成**（实测配音长度中位是原句的 0.99）。端到端同传没有词级时间戳、不能控时长，
  和「回到开口那一刻」的设计冲突，只适合作参照。

- 声纹（TitaNet，CPU 每次 0.14 秒）可以留本机；火山的流式说话人聚类若英文够准，也能一起换掉。
- 现在本机识别一小时重识别约 1100 次（每轮把上次提交点到最新整窗重送），换流式 API 后每秒音频只送一次。
- 待测：我们的音频是 5 秒一片成批到的，流式接口能否快于实时送入、句尾事件的实际延迟、时间戳怎么映回 PT（断流补静音时要一起补）。

- 翻译本来就便宜，一小时几分钱到五毛，选型只看质量和延迟。上下文窗口每句都在滑，前缀缓存基本吃不到。
- 现在本机 9B 每句 0.3–0.5 秒；API 首 token 加网络往返通常也在这个量级，要实测，p95 不能超过 2 秒左右。

| ★ **阿里 cosyvoice-v3.5-flash** | 0.8 元/万字符 | 创建音色免费；每账号最多 1000 个，满了要自己删，1 年不用自动删；样本至少 5 秒干净人声（推荐 10–20 秒）；支持自然语言指令控风格 | **2.1** |
| 阿里 cosyvoice-v3.5-plus | 1.5 元/万字符 | 同上 | 4.0 |

| 阿里 qwen3-tts-vc | 0.8 元/万字符 | 0.01 元/个，样本至少 3 秒 | 2.1 + 音色 0.3–0.5 |
| 硅基流动 CosyVoice2-0.5B | 0.05 元/千字符 | 每次请求直接带参考音，不收复刻费；这点最像现在的用法 | 0.7（若按 UTF-8 字节计为 2.0，计费单位待确认） |
| MiniMax speech-2.8-turbo / hd | 2.0 / 3.5 元/万字符 | **9.9 元/音色**，样本至少 10 秒 | 5.3 / 9.2，加音色 270–460 |
| ★ 火山 豆包声音复刻 2.0 | 3 元/万字符 | **音色槽位后付费 138 元/个**；预付费 28–138 元/个、每槽可覆盖上传 15 次 | 4.0，加音色几百到几千 |
| 腾讯 一句话复刻 | 8 元/万字符 | 训练只卖预付费包，12–39 元/个 | 10.6，加音色 320–1800 |

- 现在本机的配音每句给两个参考：这个人攒下的最干净片段（音色）+ 这句自己的原声（情绪），再按目标时长单遍控时。
  上面这些 API 都是「先注册音色、再合成」，情绪只能靠文字指令，时长只有语速参数，长度对不上要合成后再变速（`atempo`），音质会差一点。
- 新说话人第一次开口时，复刻要等攒够 5–20 秒干净人声，这之前得用别人的音色或预置音色顶上；新闻台背景音乐多，样本要先截干净。
- 一小时 600 句，CosyVoice 限 180 次/分钟，够用。

- 文档里都没有译文的词级时间戳，配音也不按原句时长出，放不回「开口那一刻」；术语表、上下文、降级策略也都不归我们管。
  要上就得另配一路识别做字幕对齐（+1 元/小时），配音按到达时刻播，等于退回市面工具的做法。
