# 调研原文

01–04 是 09-30 的选型调研，只上网查了资料，没有实测；每份报告里都有结论、对比表、实测建议和出处，汇总结论见 `../选型.md`。
06、07 是之后补的专题：06 是配音提速的实测报告，07 是迁线上 API 的调研和价格估算。

| 文件 | 内容 |
| --- | --- |
| `01-识别.md` | 英语识别、时间戳、VAD、说话人分离、声纹 |
| `02-翻译.md` | 本地翻译模型（Hy-MT2）、提示词与术语表、API 备选、端到端同传（只作参照） |
| `03-配音.md` | 中文 TTS、英语参考克隆中文、时长控制、音色和情绪分开给、参考音频怎么挑 |
| `04-分离与混音.md` | 同传式压低原声、同音色串音、克隆参考音频的提取和清理、唱歌/音乐/掌声检测 |
| `06-配音提速.md` | 配音提速：单遍控时、vLLM-Omni 路径和补丁、常驻配音服务（09-30 实测） |
| `07-线上API.md` | 迁到线上 API：各节点耗时的结论，国内识别、翻译、复刻配音、端到端同传的价格与每小时估算（10-04） |

05（拉流、延时缓冲、画面合成、交给 OBS）那份调研没有收进来，它的结论体现在 `livedub/ingest.py`、`livedub/playout.py`
和 `docs/原理.md` 里；`../选型.md` 表里出处写「05」的就是它。
