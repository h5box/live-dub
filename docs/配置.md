# 配置

三样东西，都不进 git：

| 文件 | 管什么 | 不建会怎样 |
| --- | --- | --- |
| `settings.json` | 这台机器的东西：工具和模型在哪、端口、Linux 那一侧怎么调、默认翻译模型、YouTube cookies | 用内置默认值，也就是安装脚本放东西的位置 |
| `configs/local/*.json` | 你自己的场景预设（术语表、人名、识别热词…） | 只有内置的几个场景 |
| `.secret/*.json` | 线上翻译的 API key | 线上翻译不能用（「环境」页可以直接填） |

改了 `settings.json` 要重启后端才生效（关掉窗口不够：后端会留着；在「环境」页看不到重启按钮的话，结束 `livedub.server` 进程再开）。
`uv run python -m livedub.settings` 打印最终生效的设置。

## settings.json

只写要改的项，其余用默认值。例子见 [settings.example.json](../settings.example.json)。相对路径从项目目录算起；`~` 是家目录。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `runs_dir` | `outputs/live` | 每场一个目录：分段、字幕、配音、记录 |
| `logs_dir` | `logs` | 各服务的日志 |
| `models_dir` | `models` | 本地翻译模型（GGUF）放哪 |
| `keep_media_runs` | `5` | 最近几场保留画面分段（其余只留字幕和记录；一小时 1080p 约 2–3 GB） |
| `tools.ffmpeg` / `tools.ffprobe` | `ffmpeg` / `ffprobe` | 不在 PATH 里就填完整路径 |
| `tools.llama_server` | 空 | 空：先找 `tools/llama.cpp/` 里下好的，再找 PATH |
| `tools.mediamtx` | 空 | 同上，`tools/mediamtx/` |
| `tools.js_runtime` | 空 | yt-dlp 看 YouTube 用的 JS 运行时：空则 deno、node 哪个有用哪个；也可以填路径 |
| `youtube.cookies` | 空 | cookies.txt 的路径（网站要登录时） |
| `youtube.cookies_from_browser` | 空 | 或者直接读浏览器的：`firefox`、`edge`、`chrome`… |
| `ports.asr` / `mt` / `dub` / `omni` / `rtmp` | 8091 / 8081 / 8092 / 8093 / 1935 | 各服务的端口（后端自己固定 8090） |
| `linux.runtime` | 空 | `wsl` 或 `native`；空：Windows 上用 WSL，其他系统本机 |
| `linux.distro` | 空 | 用哪个 WSL 发行版（空：默认的那个） |
| `linux.home` | `~/live-dub` | Linux 那一侧放环境和模型的目录；下面路径里的 `{home}` 指它 |
| `asr.python` | `{home}/venv-asr/bin/python` | 识别服务的 Python |
| `asr.model` / `asr.speaker_model` | `{home}/models/parakeet-tdt-0.6b-v2.nemo` / `{home}/models/titanet-large.nemo` | 识别和声纹模型 |
| `asr.device` / `asr.threads` | `cpu` / `8` | 识别用 CPU 的几个线程 |
| `dub.backend` | `omni` | `omni`（vLLM-Omni，默认，最快）、`local`（IndexTTS 进程内）、`voxcpm` |
| `dub.python` | `{home}/venv-omni/bin/python` | 配音服务的 Python（换后端时一起改） |
| `dub.vllm` / `dub.omni_dir` | `{home}/venv-omni/bin/vllm` / `{home}/vllm-omni` | omni 后端 |
| `dub.model` | `{home}/models/IndexTTS-2.5` | IndexTTS-2.5 的权重目录 |
| `dub.indextts_repo` / `dub.voxcpm_model` | `{home}/index-tts` / `{home}/models/VoxCPM2` | 另两个后端 |
| `dub.warmup_ref` | 空 | 预热用的一小段人声（Linux 路径）；空则用合成的噪声预热 |
| `dub.args` / `dub.env` | `[]` / `{}` | 给 `dubsvc/server.py` 的额外参数、额外环境变量 |
| `dub.vram_gb` | `6.5` | 只用来提示显存够不够 |
| `mt.default` | `index-9b` | 默认翻译模型（场景里没指定时） |
| `mt.gpu_layers` / `mt.ctx` | `999` / `4096` | 传给 llama-server 的 `-ngl`、`-c` |
| `mt.models` | `{}` | 增改翻译模型，见下 |
| `online` | `{}` | 增改线上接口，见下 |
| `obs.vcodec` | `auto` | OBS 输出的编码器：auto 先试 `h264_nvenc`，不行用 `libx264` |
| `obs.stream` | `livedub` | OBS 媒体源地址 `rtmp://127.0.0.1:<rtmp>/live/<stream>` |
| `obs.font_zh` / `font_zh_bold` / `font_en` | 空 | 烧字幕用的字体；空则找系统里的微软雅黑或 Noto Sans CJK |

### 翻译模型

内置四个（`livedub/mt.py` 的 `MODELS`）：

| 键 | 是什么 |
| --- | --- |
| `index-9b` | 本地，B 站 Index-Translate-9B（IQ4_XS，约 5 GB 显存）。默认 |
| `hy-mt2` | 本地，腾讯 Hy-MT2-7B（Q4_K_M） |
| `deepseek-flash` | 线上，DeepSeek |
| `custom` | 线上，自己填的任何 OpenAI 兼容接口 |

已经有 GGUF 文件的，指过去就行：

```json
{"mt": {"models": {"index-9b": {"path": "D:/models/index-translate-9b-iq4_xs.gguf"}}}}
```

加一个本地模型要写全：`file`（文件名）、`hf`（Hugging Face 仓库，`fetch.py` 从这下）、`style`（提示词格式：`index` 或 `hymt`）、
`label`、`vram_gb`。加一个线上模型：`{"api": "custom", "model": "模型名", "style": "chat", "label": "…"}`。

### 线上接口

`.secret/<接口>.json`，「环境」页保存时写的就是它：

```json
{"api_key": "sk-...", "base_url": "https://api.deepseek.com", "model": "deepseek-flash"}
```

`base_url`、`model` 可以不写（DeepSeek 有默认值）。也可以用环境变量 `DEEPSEEK_API_KEY`、`LIVEDUB_API_KEY`（给 `custom`）。
模板在 [.secret.example/](../.secret.example/)。

## 场景预设

`configs/*.json` 是内置的（通用、科技发布会、新闻、访谈），`configs/local/*.json` 是你自己的（同名时用你的）。
观看页的「场景」下拉框就是它们。一个预设的字段（都可以省略）：

| 字段 | 说明 |
| --- | --- |
| `name` | 下拉框里显示的名字 |
| `src` | 默认的链接或视频路径（一般留空，开始时再填） |
| `domain` | 一句场景说明，放进翻译提示词：「这是{domain}的语音识别结果…」，比如 `英文科技发布会直播` |
| `delay_s` | 默认延时 D（秒，10–120） |
| `glossary` | 术语表 `{"原文": "译法"}`，命中的词会提示给翻译模型 |
| `names` | 人名、产品名：识别拼错时按编辑距离纠正，线上翻译时提示照原文写 |
| `asr_boost` | 识别热词（短语列表），提高这些词被认出来的概率；改了会重启识别服务 |
| `asr_boost_alpha` | 热词的权重（默认 2.0） |
| `mt_model` | 这个场景用的翻译模型（不写用 `mt.default`） |
| `mt_target_cps` | 译文目标语速（字 / 秒，默认 5.0），配音稿要和原话差不多长 |
| `mt_compact_at` | 线上翻译：上下文到多少 token 就把前文压缩成摘要（默认模型上下文的一半） |
| `mt_api_prompt` / `mt_api_thinking` / `mt_api_temperature` | 线上翻译的提示词版本（默认 v5）、思考模式（默认 off）、温度 |
| `speaker_threshold` | 声纹聚类的门槛（默认 0.45，越高越容易分成新的说话人） |
| `max_height` | 拉流的最高分辨率（默认 1080） |
| `cookies` | 这个源专用的 cookies.txt |
| `tag` | OBS 输出角落里的标注（默认「AI 翻译配音」） |
| `sub_bottom` / `sub_box` / `tag_corner` | OBS 输出的字幕离底边多少像素、背景框不透明度、标注在哪个角（新闻台底部有自己的字幕条时用） |

例子：一场固定的发布会

```json
{
 "name": "某某发布会",
 "domain": "英文科技发布会直播",
 "names": ["Satya", "Copilot", "Azure"],
 "asr_boost": ["Satya Nadella", "Copilot", "Azure"],
 "glossary": {"Copilot": "Copilot", "agent": "智能体", "keynote": "主题演讲"}
}
```
