# 大众用户改进

目标：Windows 普通用户完成安装与引导后，先用原生 CPU 中文字幕，配音按需安装。

| 顺序 | 工作 | 状态 |
| --- | --- | --- |
| P0 | Windows NSIS 安装包、打包后端与首次组件下载 | 完成，独立后端与真实工具下载验证通过 |
| P0 | 原生 CPU Parakeet/TitaNet，保留词级时间戳、标点与声纹 | 完成，真实语音及仅字幕实跑通过 |
| P0 | 首次向导：下载、翻译接口测试、英语测试片 | 完成，前端构建及打包版测试片验证通过 |
| P1 | 简化观看页与延时文案 | 完成，前端构建与页面检查通过 |
| P1 | 点播提前处理与目标位置优先处理 | 完成，真实 CPU 识别长视频跳转通过 |
| P1 | 故障原因和恢复操作 | 完成，启动失败与播放器重试操作可用 |
| P2 | 历史回放、继续观看、字幕导出和缓存清理 | 完成，播放、续看、导出、清理实测通过 |

原生识别当前不支持 NeMo 的热词增强；场景术语表仍用于翻译。
字幕实跑使用本机生成的英语语音与视频，真实 ONNX 识别、假兼容翻译接口，不消耗付费 API。
长视频跳到约 100 秒，处理范围从前段扩展到目标位置；切换页面未出现重复音频节点错误。
历史视频播放位置约 8 秒，重开播放器恢复误差小于 0.1 秒；清理后 16 句字幕保留。
pytest 13 项通过；新增原生识别、下载、设置模块 pyright 通过。
打包后端使用独立数据目录和仅含 System32 的 PATH：FFmpeg 自动下载、doctor、英语测试片字幕链路通过。
最终安装包解出后复测：Deno 安装、字幕链路、内置场景隔离通过；桌面外壳能自动启动内置后端。
安装包仅包含内置场景，不包含个人预设、设置和密钥；模型仍由首次向导下载。
