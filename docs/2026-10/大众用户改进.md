# 大众用户改进

目标：Windows 普通用户完成安装与引导后，先用原生 CPU 中文字幕，配音按需安装。

| 顺序 | 工作 | 状态 |
| --- | --- | --- |
| P0 | Windows NSIS 安装包、打包后端与首次组件下载 | 实现，安装包验证中 |
| P0 | 原生 CPU Parakeet/TitaNet，保留词级时间戳、标点与声纹 | 实现，真实语音及仅字幕实跑通过 |
| P0 | 首次向导：下载、翻译接口测试、英语测试片 | 实现，前端构建通过 |
| P1 | 简化观看页与延时文案 | 待处理 |
| P1 | 点播提前处理与目标位置优先处理 | 待处理 |
| P1 | 故障原因和恢复操作 | 待处理 |
| P2 | 历史回放、继续观看、字幕导出和缓存清理 | 待处理 |

原生识别当前不支持 NeMo 的热词增强；场景术语表仍用于翻译。
字幕实跑使用本机生成的英语语音与视频，真实 ONNX 识别、假兼容翻译接口，不消耗付费 API。
尚需干净 Windows 机器和非技术用户验证；本机验证不能证明所有机器的安装成功率。
